# ♻️ Smart Waste Management & Citizen Engagement Platform

A web-based platform designed to improve urban cleanliness by enabling citizens to report waste issues and helping authorities manage waste collection efficiently.

---

## 📌 Project Overview

The Smart Waste Management System connects citizens and municipal authorities through a digital platform. Users can report waste issues, track complaint status, and contribute to maintaining a cleaner environment.

This project promotes:
- 🌱 Environmental sustainability  
- 🏙️ Smart city development  
- 👥 Citizen participation  

---

## 🚀 Features

- 🗑️ Report waste issues with details
- 📍 Track waste locations
- 📊 Dashboard for monitoring reports
- 🔐 User authentication (Login / Register)
- 📈 Status updates for reported complaints
- 🧑‍💼 Admin panel for managing reports
- 📱 Responsive design (Mobile + Desktop)

---

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

git clone https://github.com/your-username/smart-waste-management.git  
cd smart-waste-management  

### 2️⃣ Install dependencies

For frontend:

cd frontend  
npm install  
npm run dev  

For backend:

cd backend  
npm install  
npm start  

---

## 🔑 Environment Variables

Create a `.env` file in the backend folder:

PORT=5000  
MONGO_URI=your_mongodb_connection_string  
JWT_SECRET=your_secret_key
